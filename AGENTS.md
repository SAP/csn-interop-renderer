## ORD UI integration

For UI that may be embedded in Open Resource Discovery Metadata Renderer, use `@open-resource-discovery/ui-components` (currently `0.2.0`) and its public `--ord-*` design tokens. Prefer the library's components and stylesheet over bespoke controls and hard-coded visual values, so the renderer inherits the host's ORD theme consistently.
